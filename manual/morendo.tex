\chapter*{About this manual}
\addcontentsline{toc}{chapter}{About this manual}

\Morendo\ is a RETE inference engine written in Java. It reads rules in the
CLIPS language, matches them against facts and Java objects, and fires the
rules whose conditions hold. This manual is both a tutorial and a reference
for version \version.

Part~I is the tutorial: it installs the engine, walks through a first
session in the interactive shell and then introduces the language one
construct at a time, the CLIPS constructs and functions \Morendo\ reads
included. Part~II covers the features \Morendo\ adds to plain CLIPS:
Java objects as facts, rule properties, queries, MOLAP cubes, temporal
facts, the \fn{only} and \fn{multiple} conditional elements, and rule
cost analysis. Part~III describes the shell, the graphical interface and
how to embed the engine in a Java program, alone or as a pool of engines
serving many threads. The appendices list every built-in function,
summarize the grammar and list the differences from CLIPS.

\paragraph{Conventions.} Code, file names and function names are set in
\fn{monospace}. Shell sessions are shown as they appear on the terminal,
with the \fn{Morendo>} prompt in front of each input line. Variables in
CLIPS begin with a question mark, as in \fn{?name}. Comments in rule files
are introduced by two semicolons, \fn{;;}. File paths are given relative to
the root of a \Morendo\ checkout or unpacked distribution.

Every example in Part~I and Part~II was run against \Morendo\ \version; the
transcripts are real output, except that timestamps and profiling times
vary from run to run. The tutorial's transcripts are one continuous
session, so the fact ids follow on from one section to the next.
